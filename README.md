# Urbanite
The URBANITE dataset is a synthetic multi-camera CCTV dataset designed for security and safety applications in urban environments. It includes over 40 hours of footage, featuring 7 different security events, 25,000 pedestrians, 100,000 tracks, and 16 actions. The dataset provides rich multi-task annotations, including 2D and 3D bounding boxes, 3D human skeletons, and instance segmentation masks, all structured using the ASAM OpenLABEL standard.
